# CyberShield

CyberShield is a cybersecurity project for detecting and mitigating AI-based cyber attacks in social media and websites using intelligent security models.

## Project Components

- Machine Learning models for cyber attack detection
- FastAPI ML service
- Next.js web application
- Cybersecurity datasets for model training and evaluation

## Project Structure

- `ml/` — Machine learning work, datasets, notebooks, models, and reports
- `ml-service/` — FastAPI backend for serving ML models
- `web/` — Next.js frontend
- `docs/` — Project documentation
